Subject: Open-Source Software Defined Vehicle Platform - 18 Custom ESP32 Modules on CAN Bus with Local AI Voice Control

Hi Hackaday,

I've been building TrailCurrent, an open-source Software Defined Vehicle platform that turns any RV, trailer, boat, or UTV into a smart, connected vehicle with zero cloud dependency.

The core of the system is 18 custom ESP32-based hardware modules (all with custom KiCAD PCBs) communicating over a 500 kbps CAN bus network. Each module handles a specific function:

- Torrent: 8-channel PWM lighting controller with animated sequences
- Switchback: 6-channel relay control (10A @ 250V AC)
- Bearing: GNSS positioning with 9-DOF orientation
- Borealis: Environmental sensing (SHT31-D temp/humidity, SGP30 CO2/TVOC)
- Plateau: 9-axis IMU vehicle leveling with per-corner height calculation
- Ampline/Solstice: Battery and solar monitoring via Victron VE.Direct
- Picket: 10-channel reed switch door/cabinet monitor
- Aftline: 7-pin trailer connector analyzer
- Fireside: 7" capacitive touchscreen dashboard (ESP32-P4, LVGL)
- Peregrine: Fully offline AI voice assistant running Llama 3.2 1B on a Qualcomm Hexagon NPU (~12 tokens/sec), with custom wake word detection, faster-whisper STT, and Piper TTS

The in-vehicle compute layer (Headwaters) runs on a Raspberry Pi Compute Module 5 (CM5) on a standard carrier board with a Waveshare RS485 CAN HAT (B) — fully off-the-shelf, no custom PCBs. It runs 5 Docker containers: MQTT broker (Mosquitto), Node.js backend (CAN-to-MQTT bridge + REST API), MongoDB, an offline vector tile map server, and a local web dashboard. The vehicle operates completely autonomously - cloud sync is optional and self-hosted.

A key design principle is that every critical control (heaters, fans, motors) has a hardwired physical backup. WiFi and software are never the only path to a safety-critical function.

The entire stack is open source: firmware (PlatformIO/Arduino), 13 custom PCB designs with 31 hierarchical KiCAD schematic sheets, 18 custom FreeCAD enclosure models, Docker deployment configs, a Kotlin Android app, and a vanilla JS web dashboard. No proprietary dependencies anywhere.
